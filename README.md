# Lab3

Класс MatrixTask (Задания 1–2)

Конструкторы:

MatrixTask(int n, int m) — создаёт матрицу n x m с вводом с клавиатуры по столбцам.
Почему: чтобы пользователь мог задать точные значения.
Как: цикл по столбцам, внутри — цикл по строкам, int.Parse(Console.ReadLine()).

MatrixTask(int n) — квадратная матрица n x n, заполнение случайными числами относительно побочной диагонали.
Почему: демонстрация генерации случайных матриц и работы с индексами.
Как: если i + j < n - 1 — верхняя часть, иначе — нижняя часть диагонали, значения выбираются из разных диапазонов.

MatrixTask.CreateSpecial(int n) — специальная матрица.
Почему: задание по формированию матрицы по конкретной схеме.
Как: внутренний цикл по столбцам и строкам, заполняем снизу вверх и справа налево.

Метод FindMax3x3Sum()
Почему: нужно найти подматрицу с максимальной суммой для анализа данных.
Как: двойной цикл по всем возможным 3x3 блокам, считаем сумму, сохраняем максимум.


Класс FileTasks (Задания 6–8)

Текстовый файл с числами по одному в строке
FillTextFileNumbers(path, count) — генерирует случайные числа.
Звчем: нужен источник данных для анализа.
Как: StreamWriter и Random.Next(-100,101).

DifferenceMaxMin(path) — разница между max и min.
Зачем: простой анализ данных в файле.
Как: File.ReadAllLines(), int.Parse(), Max() - Min().

Поиск минимального элемента
FindMinElement(path) — возвращает минимальный элемент.
Почему: проверка функции поиска min для анализа файла.
Как: LINQ Min() по массиву чисел.

Копирование строк, начинающихся с символа
CopyLinesStartingWith(source, target, symbol)
Почему: фильтрация строк по условию.
Как: File.ReadAllLines().Where(l => l.StartsWith(symbol.ToString())).

Исходный файл:

Скопированные строки (начинаются с 'A'):
